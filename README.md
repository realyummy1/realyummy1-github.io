# Guanheng Cheng — Academic Homepage

A static academic homepage for https://realyummy1.github.io/.

## Publish with GitHub Pages

1. Use the repository `realyummy1/realyummy1.github.io`.
2. Commit these files to the `main` branch, with `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, select **main** and **/ (root)**, and save.
5. Wait for the GitHub Pages deployment to finish.

No package installation or build is required. The `.nojekyll` file tells GitHub Pages to serve the static files directly.

## Update the homepage

Edit `index.html`, `styles.css`, or `script.js`, then push the changes to `main`. Keep the `assets/` folder and `fonts.css` in place.

All photographs, university emblems, framework figures, patent diagrams, and font files used by the page are included. Research manuscripts and patent source documents are not included.
